一、针对谁

1.1 三层用户

层 是谁 他们的痛
直接使用者 社区小店 / 夫妻店 店主、店长 不会看（不知道店里哪里有问题）、不会算（不知道进什么进多少）、不会卖（不会做活动）、没时间
买单方 / 渠道 同福集团等供应链企业、连锁零售品牌 想赋能海量合作小店，但人工巡店贵、标准落不下去、没法一对一带
生态 初芯平台、人民网 需要可复制、可推广、服务实体经济的零售智能体样本

1.2 核心判断

小店缺的不是一套系统，而是一个会经营的人。SaaS 给小店的是报表，小店看不懂也不会用；AI 店长给的是结论和动作：「这排货架缺 3 个单品，今天补」「这 12 件鲜食 3 天内到期，建议这样促销」。

呼应同福集团总裁刘辉在 2026-10-10 金台圆桌会上的判断：小店最关心的是「成本怎么控、商品怎么选、货源怎么保障、经营效率能否提升」，技术价值「不在于功能有多复杂，而在于能否帮经营者更好地选品、管货、服务顾客」。

二、做什么：1 个入口 + 3 个动作 + 1 份报告

2.1 入口：对话式 AI 店长

小店店主打开就能用，不需要培训、不需要装设备。语音或文字说一句「帮我看看今天店里有什么问题」，或直接拍照。

2.2 动作一：AI 巡店（看成什么样）

  • 店主拍货架、价签、冷柜、后仓照片（或口述）
  • AI 识别：缺货空置、价签不符、陈列错位、临期/过期、卫生与安全项
  • 输出：整改清单（问题 + 证据 + 标准要求 + 整改期限 + 复查项）

2.3 动作二：AI 算账（该进什么、进多少）

  • 输入：一周销量、库存（表格导入或口述）
  • 输出：补货建议单（按动销、保质期、天气/节假日）、选品建议（爆品清单 + 毛利结构）、定价建议（引流款/利润款）
  • 数据来源：同福商品库 + 门店导出的进销存表格

2.4 动作三：AI 卖货（怎么把它卖掉）

  • 输入：临期清单 / 活动目标
  • 输出：临期促销方案、社群话术、海报文案、活动方案

2.5 交付物：每周经营体检报告

红黄绿灯总分 + 3 条最该改的问题 + 整改清单 + 下周动作。这是小店「看得见」的价值，也是总部「管得住」的抓手。

2.6 闭环

拍/说/导表格 → AI 诊断（知识库对照）→ 报告与清单 → 店主整改 → 复查 → 下周报告

三、适配场景（对应征集表勾选项）

勾选 场景 在本作品中的角色

四、技术路径

4.1 平台组件（扣子实现）

组件 承担什么
智能体 统一入口：对话、问答、引导输入、组织输出
知识库 检查项与判定标准、缺陷分级与整改模板、诊断报告模板（可替换为客户/同福的自有标准）
视觉多模态 照片识别货架排面、价签、效期标识；看不清时要求重拍，不猜测
快捷指令 一键诊断 / 拍照巡店 / 出整改清单，降低使用门槛
参数控制 温度 0.3 + 最大回复长度拉满，保证报告可复现、不截断

初芯版本同步搭建：同一套提示词与知识库可直接迁移，说明方案不绑定单一平台；评分与报告逻辑保持一致。

4.2 关键设计

  1. 证据链：每条结论必须对应「检查项 + 证据 + 标准要求」，可追溯；无证据判「待补充」，不编造。
  2. 确定性评分：单检查点扣分规则固定（符合 0 / 轻微 10 / 严重 25），总分与红黄绿灯可复算。
  3. 固定模板：报告结构固定，不因模型波动而变。
  4. 人工复核开关：前 10 份报告由人工复核后发出，保证产品信誉期质量。

4.3 数据来源与降级方案

理想态 现实降级（首版即可用）
门店 POS / 进销存 API 直连 导出 Excel 导入，或口述
摄像头自动巡检 店主手机拍照
商品主数据自动同步 上传同福商品清单表格

零硬件、零系统对接也能跑——这是本作品能被百万小店用起来的前提。

4.4 可复制性

换一个品牌 = 换一套知识库与检查项，3 天可上线；智能体与工作流不改。

五、应用成效（可验证口径）

试点口径：1 个品牌、10 家社区小店、4 周。

指标 现状（人工） 目标 测量方式
单店巡店耗时 30–40 分钟/次 ≤ 5 分钟 店主操作计时
巡店频次 每月 1 次（或没有） 每周 1 次 报告生成记录
经营诊断报告产出 0 每周每家 1 份 报告数

生鲜损耗率 基线待测 下降 15% 报损记录

说明：上述为试点目标值，基线在试点首周测得；答辩时用真实前后对比数据替换。

六、落地路径（与同福的合作闭环）

6.1 角色分工

角色 出什么
同福集团等供应链企业 商品库与货源、仓配、门店网络、运营标准（这正是同福「风险先扛、先探路」的能力）
初芯平台 大模型接口、知识库、工作流、发布与分发能力
本作品 智能体 + 诊断方法论 + 检查项与整改知识库 + 报告体系

6.2 三步走

  1. 10 店试点（1 个月）：验证「拍照→报告→整改」闭环
  2. 1 个区域 100 店（3 个月）：跑通同福供货数据对接，形成标准包
  3. 万店复制（12 个月）：标准包按品牌复制，知识库即标准

6.3 商业模式

小店低门槛使用（免费版/低价订阅）；同福通过供货与复购获益；平台按调用计费。三方各取所需，不靠小店单独付费起步。

七、创新点（答辩三点）

  1. 零硬件、零学习成本：一部手机、说几句话，夫妻店就能用——不是又一个要装摄像头的方案。
  2. 内控审计方法论做门店诊断：有标准、有证据、有缺陷分级、有整改复查闭环，不是「AI 聊天」，报告可对总交付、可追责。
  3. 知识库即标准：一套智能体 + 可替换知识库，适配不同品牌与业态，天然可复制推广。

1:30 整改清单 展示「问题+证据+标准+期限」
2:00 算账 导入一周销量 → 补货单 + 选品建议
3:00 卖货 临期清单 → 促销方案 + 社群话术
3:30 经营体检报告 红黄绿灯 + 下 3 条动作
4:00 落地路径 同福供货 + 初芯平台 + 万店复制

演示链接要求：软件方向需「可体验全部功能的使用链接」——发布为初芯可公开访问的智能体，确保评审点开即用、无需后台权限。

九、边界与合规

  • 不涉及硬件与现场施工，不与任何智能终端绑定。
  • AI 给建议，决策权在店主；报告明确标注「AI 辅助诊断，需人工复核」。
  • 门店经营数据归属与授权在合作协议中约定；照片仅用于本次诊断，不留存超出必要期限。
